# PianoP2P
🎹 Piano Compartilhado P2P: Toque com amigos em tempo real direto no navegador! 🚀 Sistema multijogador via PeerJS (sem servidor), sintetizador dinâmico (Sine, Square, Sawtooth, Triangle) e visualizador de partículas. Totalmente PWA e focado em privacidade (sem coleta de dados). Inspirado no Shared Piano. 🎵✨
